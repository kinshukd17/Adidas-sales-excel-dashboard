# 📊 Adidas Sales Dashboard (Excel)

## 📌 Project Overview

This project showcases an interactive **Adidas Sales Dashboard** built entirely in **Microsoft Excel**. The dashboard transforms raw sales data into meaningful business insights using **PivotTables, PivotCharts, KPI Cards, and Interactive Slicers**.

It enables users to analyze sales performance across different regions, retailers, product categories, and sales methods, helping identify trends and support data-driven decision-making.
